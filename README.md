# Hana Nguyen — Personal Portfolio & CV (`github.io`)

Trang web cá nhân được thiết kế theo phong cách **Odyssey Theme** (`treefarmstudio/odyssey-theme`) với bộ font chữ cổ điển - hiện đại (`Lora` & `Plus Jakarta Sans`), bố cục thẻ bo góc tinh tế và thanh chuyển đổi màu giao diện (**Theme Switcher**) đặc trưng.

## Cấu trúc thư mục
- `index.html`: Trang chủ giới thiệu bản thân (đã chỉnh sửa ngữ pháp tiếng Anh), liên kết mạng xã hội (YouTube, LinkedIn, TikTok) và toàn bộ nội dung CV.
- `projects.html`: Trang giới thiệu các dự án giáo dục, mở đầu với dự án **HOC247 Kids** và nhúng trực tiếp 3 video YouTube.
- `styles.css`: Tập tin giao diện CSS hỗ trợ 4 bảng màu lấy cảm hứng từ Odyssey Theme (Classic Forest, Ocean, Terracotta, Dark).

## Cách đưa lên GitHub Pages (`github.io`) nhanh nhất
1. Đăng nhập vào GitHub và tạo một repository mới có tên `<ten-tai-khoan-github-cua-ban>.github.io` (ở chế độ **Public**).
2. Tải lên 3 file `index.html`, `projects.html`, và `styles.css` vào nhánh `main` của repository.
3. Vào mục **Settings** -> **Pages** của repository, ở phần **Build and deployment**, chọn **Deploy from a branch** -> nhánh `main` -> `/ (root)` rồi bấm **Save**.
4. Sau 1–2 phút, trang web của bạn sẽ hoạt động tại địa chỉ `https://<ten-tai-khoan-github-cua-ban>.github.io`.
